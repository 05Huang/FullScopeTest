# API 测试指南

## 概述

API 测试模块支持对 RESTful API 进行完整的测试验证，包括请求发送、响应校验、断言配置、环境管理和批量执行。

## 核心功能

### 测试工作台

测试工作台是 API 测试的核心界面，分为四个区域：

1. **请求编辑区** — 配置请求方法、URL、Headers、Body、Query Params
2. **响应展示区** — 查看响应状态码、Headers、Body、耗时
3. **断言配置区** — 设置响应断言规则
4. **脚本编辑区** — 编写前置/后置脚本

### 用例管理

- **创建用例**：在工作台中配置好请求后保存
- **用例集管理**：将用例组织到集合中，方便批量执行
- **导入用例**：支持从 Postman Collection 或 CSV 文件导入
- **导出用例**：支持导出为 cURL 命令

### 环境管理

环境变量允许在不同环境（开发/测试/生产）间切换配置：

1. 创建环境（如「开发环境」「测试环境」）
2. 添加变量（如 `base_url`、`api_key`）
3. 在用例中使用 `{{变量名}}` 引用变量
4. 执行时选择目标环境

### 断言

支持以下断言类型：

| 断言类型 | 说明 | 示例 |
|---------|------|------|
| 状态码 | 检查 HTTP 状态码 | `status == 200` |
| 响应时间 | 检查响应耗时 | `response_time < 1000` |
| JSON Path | 检查 JSON 响应字段 | `$.data.id > 0` |
| 包含文本 | 检查响应体包含指定文本 | `body contains "success"` |
| Header | 检查响应头 | `Content-Type contains "json"` |

### 批量执行

1. 在用例列表中勾选多个用例
2. 点击「批量执行」
3. 选择执行环境
4. 查看执行结果报告

### 版本历史

- 每次修改用例自动保存版本快照
- 支持查看历史版本和版本间 Diff 对比
- 最多保留 50 个版本

## 最佳实践

1. **合理组织用例集** — 按功能模块或接口分组
2. **使用环境变量** — 避免硬编码 URL 和 Token
3. **配置断言** — 不要只检查状态码，还要校验关键字段
4. **定期执行回归测试** — 利用 CI/CD 集成自动化执行
