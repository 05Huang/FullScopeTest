# 快速开始指南

> 5 分钟内完成你的第一次 API 测试

## 1. 注册与登录

1. 访问平台首页，点击「注册」
2. 填写用户名、邮箱和密码（密码至少 8 位，包含大小写字母和数字）
3. 注册成功后自动跳转到登录页
4. 输入凭据登录

## 2. 创建项目

1. 登录后，顶栏显示项目选择器
2. 点击项目选择器，选择「创建新项目」
3. 输入项目名称（如「我的第一个项目」）和描述
4. 点击确认创建

## 3. 创建 API 测试用例

1. 在左侧导航栏点击「接口测试」→「测试工作台」
2. 点击「新建用例」按钮
3. 填写用例信息：
   - **名称**：如「获取用户列表」
   - **方法**：选择 GET
   - **URL**：输入 `https://jsonplaceholder.typicode.com/users`
4. 点击「发送请求」按钮
5. 查看响应结果（状态码、响应体、耗时）

## 4. 执行测试

1. 在用例列表中选择要执行的用例
2. 点击「执行」按钮
3. 在测试报告页面查看执行结果

## 5. 查看报告

1. 点击左侧导航栏「测试报告」
2. 查看执行统计、通过率趋势、详细结果
3. 支持导出 JSON/Excel/PDF/CSV 格式
