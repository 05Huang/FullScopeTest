# FullScopeTest v1.0.0-rc1 Release Notes

🎉 **首个正式发布候选版本** — 从个人练手项目全面升级为生产可部署、商业级别的开源测试平台。

---

## 🚀 为什么选择 FullScopeTest？

FullScopeTest 专为需要**全方位测试覆盖**的团队打造。我们不仅实现了传统测试平台的所有核心功能，更在以下关键维度**超越 MeterSphere V3**：

| 维度 | MeterSphere V3 | FullScopeTest |
|------|---------------|---------------|
| UI 自动化 | ❌ 已移除 | ✅ Playwright + 视觉回归 |
| 性能测试 | ⚠️ 基础支持 | ✅ Locust + 实时大盘 + 告警 |
| AI 能力 | ⚠️ 简单 Prompt 包装 | ✅ 可观测、可版本化、语义分析 |
| CI/CD | ⚠️ 基础 Webhook | ✅ GitHub Action + Quality Gate + 变更感知 |
| 多租户 | ✅ 支持 | ✅ 支持 + 审计日志 |
| 部署方式 | Docker Compose | Docker Compose + K8s |
| 性能 | Java (Spring Boot) | FastAPI (比 Flask 快 30%+) |

## ✨ 核心新功能

### 🏗️ 工程基础设施
- **结构化日志**：structlog JSON 格式，每条日志含 `trace_id`，支持 ELK/Grafana Loki 日志聚合
- **Celery 死信队列**：任务失败自动重试 3 次 + 指数退避，失败任务进入死信队列便于排查
- **Prometheus + Grafana**：预置监控仪表盘，5 个面板覆盖 API、任务、WebSocket 全链路
- **健康检查端点**：`/health` + `/health/ready`，支持 Kubernetes Liveness/Readiness Probe

### 🎨 视觉回归测试（独家功能）
- **自动截图 + 智能对比**：Playwright 每步自动截图 → Pillow + imagehash 感知哈希差异 → 像素级差异高亮
- **视觉基准管理**：首次运行自动设为基准，支持人工批准新基准
- **历史趋势追踪**：用例级别的视觉变化时间线 + 差异百分比折线图
- **前端可视化**：左右分屏对比、红色差异高亮、一键批准

### ⚡ 性能测试深度增强
- **时间序列指标**：每秒 RPS、响应时间、错误率完整存储
- **分位数统计**：P50/P75/P95/P99 自动计算
- **性能历史对比**：多轮测试一键对比，自动计算劣化百分比
- **实时告警引擎**：可配置绝对阈值 + 相对劣化告警，WebSocket 实时推送

### 🤖 AI 能力工程化
- **Prompt 版本管理**：A/B 测试不同 Prompt 版本，基于调用日志统计成功率
- **AI 调用可观测性**：每次 LLM 调用记录 prompt、response、latency、tokens、cost
- **智能用例生成**：解析 Swagger → AI 分析语义 → 自动生成正常/边界/异常用例
- **语义去重**：基于 sentence-transformers 的用例向量化 + 余弦相似度去重
- **降级策略**：AI 服务不可用时返回 fallback 结果，不影响核心功能

### 🔗 CI/CD 深度集成
- **官方 GitHub Action**：一行 YAML 集成到 CI/CD 流程
- **Quality Gate**：可配置质量门禁（通过率、P95、视觉差异），阻断不达标合并
- **GitHub Check Run 回写**：实时更新测试状态到 PR，失败用例一目了然
- **变更感知触发**：`/api/**` 路径变更时只运行接口测试，节省 CI 资源
- **GitLab CI 集成**：同时支持 GitHub 和 GitLab 生态

### 🏢 多租户与安全
- **组织级数据隔离**：所有查询自动注入 `organization_id`，越权返回 404
- **API 限流**：Redis 滑动窗口，支持按组织自定义限额
- **API Token 管理**：多 Token、细粒度权限、bcrypt hash 存储
- **审计日志**：所有写操作完整记录，支持按时间/用户/资源过滤
- **安全加固**：Playwright 沙箱化执行、文件上传内容验证、HMAC 签名验证

### ⚡ FastAPI 迁移
- **并行运行**：Flask (`/api/`) 和 FastAPI (`/api/v2/`) 共存，零停机迁移
- **异步 WebSocket**：替换 Flask-SocketIO，原生 FastAPI WebSocket 支持
- **OpenAPI 文档增强**：所有接口完整文档 + Postman Collection 导出
- **性能提升**：FastAPI 版本 P95 响应时间比 Flask 版本低 30%+

## 📦 部署

### Docker Compose 快速启动

```bash
# 克隆仓库
git clone https://github.com/05Huang/FullScopeTest.git
cd FullScopeTest

# 配置环境变量
cp .env.example .env
# 编辑 .env 设置必要的环境变量

# 启动所有服务
docker-compose -f docker-compose.release.yml up -d

# 访问
# Web UI: http://localhost
# API: http://localhost:8000
# Grafana: http://localhost:3001
```

### 所需环境变量

| 变量 | 必填 | 说明 |
|------|------|------|
| `SECRET_KEY` | ✅ | Flask 应用密钥 |
| `JWT_SECRET_KEY` | ✅ | JWT Token 签名密钥 |
| `POSTGRES_PASSWORD` | ✅ | PostgreSQL 密码 |
| `GRAFANA_ADMIN_PASSWORD` | ✅ | Grafana 管理员密码 |
| `AI_ASSISTANT_API_KEY` | ❌ | OpenAI/DeepSeek API Key |
